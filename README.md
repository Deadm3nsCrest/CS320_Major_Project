# Ward Registry System

A web application for registering and recording individuals from tribes in villages and clans for voting eligibility tracking.

## Project Overview

This project models the hierarchy:

Village -> Tribe -> Clan

A user can:
- browse villages with descriptions
- select a tribe
- open a registration form
- register a resident with required civil-registry-style details
- view success/error states
- see required fields flagged with a red asterisk
- interact with a modern dark green and black themed interface

## Features Implemented

- dark green + black aesthetic with translucent background image overlay
- hover animations on buttons and cards
- glowing title effect for `Ward Registry System`
- village cards with descriptive text
- tribe selection and registration form
- validation for required fields
- save button disabled when the form is invalid
- success message after registration
- decorative footer pattern inspired by traditional craft/workmanship styles
